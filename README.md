# Visitenkarten-Webseite für Herrn M.

Statische, persönliche Visitenkarten-Webseite mit Startseite, Kontaktseite und Impressum.

Sämtliche Inhalte, Namen, Adressen und Kontaktdaten sind fiktiv und dienen ausschließlich Demonstrationszwecken.

Enthält zwei Kontakt-Icon-Varianten unter `variants/` (uneinheitlich vs. einheitlich ausgerichtet).
